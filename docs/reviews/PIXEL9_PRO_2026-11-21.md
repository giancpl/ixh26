## Local reproduction and retained artifacts

This test project publishes them on host ports 38080 and 37777, preserving other
projects already occupying the default ports. Its **public URL remains 8080**
because media URLs and NIP-98 authorizations must agree with phone URLs:

```sh
export PHOTOANCHOR_PROJECT=photoanchor-v3 PHOTOANCHOR_IMAGE_PREFIX=photoanchor-v3
export PHOTOANCHOR_API_PORT=38080 PHOTOANCHOR_RELAY_PORT=37777
export PHOTOANCHOR_PUBLIC_URL=http://127.0.0.1:8080
export PHOTOANCHOR_OPERATOR_DIR=./social-artifacts/pixel9-pro-acceptance/phone-operator
adb -s "$PIXEL_SERIAL" reverse tcp:8080 tcp:38080
adb -s "$PIXEL_SERIAL" reverse tcp:7777 tcp:37777
adb -s "$PIXEL_SERIAL" install -r social-artifacts/photoanchor-debug.apk
adb -s "$PIXEL_SERIAL" shell am start -n com.example.photoanchor/.MainActivity
./scripts/social-mine.sh --event EVENT_ID --timeout 120
```
